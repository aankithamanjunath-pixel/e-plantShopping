# e-plantShopping

## Paradise Nursery – Online Plant Shopping Cart Application

e-plantShopping is a React-based shopping cart application developed for an online plant nursery called Paradise Nursery. The application allows users to browse a variety of house plants, add plants to the shopping cart, manage item quantities, and view the total cost dynamically.

### Features
- Landing page with a Get Started button
- Navigation bar with links to Home, Plants, and Cart
- Product listing page displaying plants with images, descriptions, and prices
- Categorized plant sections such as Aromatic Plants and Medicinal Plants
- Shopping cart functionality with quantity control and delete option
- Dynamic cart count and total price calculation using Redux
- Responsive and user-friendly interface

This project is developed as part of the final React and Redux practice project and demonstrates component-based architecture, state management using Redux Toolkit, and dynamic UI rendering.
